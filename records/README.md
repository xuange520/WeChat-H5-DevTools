# 版本记录归档与排错溯源管理规约 (Version Records Architecture)

## 核心设计铁律 (Core Principles)

根据项目版本管理与故障溯源规约，严禁将所有版本记录混杂在同一个文件夹或单一文件中，必须遵循**“一版本一目录、独立文件、物理隔离”**的原子化存储架构：

```text
records/
├── README.md                  # 本说明规约文档
├── v1.0.0/                    # v1.0.0 版本独立专有归档目录
│   ├── version_record.md      # 人类可读排错溯源档案 (详细排错、内核基线、改动点)
│   ├── version_record.json    # 机器可读结构化元数据 (便于自动化排障比对)
│   └── checksums.sha256       # 当前版本产物唯一物理哈希指纹
├── v1.0.1/                    # 未来新版本独立目录 (互不干扰)
└── v1.1.0/                    # ...
```
