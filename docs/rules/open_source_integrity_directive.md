# 开源技术诚信与溯源鸣谢守卫准则 (Open Source Integrity & Attribution Directive)

## 01. 核心准则与工程诚信
- **全面披露**：凡在系统研发、内核逆向、网络代理、解混淆及架构设计过程中直接依赖、间接调用或受到思路启发的开源项目，100% 必须完整、清晰披露，严禁抹杀原作者贡献；
- **双向同步存证**：
  - **文档层**：在 README.md 与 README_EN.md 中强制设立专门的“开源引用、技术借鉴与鸣谢 (Attribution)”章节；
  - **应用层**：桌面端/Web 端软件界面中必须内置“开源鸣谢”独立菜单或关于面板，完整渲染第三方项目的 GitHub 仓库链接、作者与开源许可证；
- **表格规范**：
  必须采用 GFM 原生富文本表格展示，字段包含：项目名称、作者/组织、官方仓库地址 (GitHub 完整 URL)、开源许可证、核心借鉴价值/应用场景。

## 02. 免责声明与非商业防倒卖硬门禁 (Anti-Resale Ban)
- **双重落盘**：README.md 与软件 GUI 界面中必须 100% 显式包含严厉的非商业与防倒卖免责声明；
- **严禁倒卖**：严正禁止二手贩子、黑产团伙在闲鱼、淘宝、拼多多、自动发卡网等平台打包变相售卖免费开源成果；
- **维权保留**：明确保留证据公证、全网下架维权与追究法律责任的权利。
